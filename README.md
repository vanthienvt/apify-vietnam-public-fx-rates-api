# Vietnam Public Exchange Rates & VND Currency Converter API

Provides automated, structured public reference exchange rates for **Vietnamese Dong (VND)** against major international currencies including **USD, EUR, JPY, GBP, SGD, KRW, CNY, AUD, CAD, THB, CHF, and HKD**.

## Why Use This Actor?
- **100% Public Financial Data:** Uses open global foreign exchange reference feeds with zero authentication overhead.
- **Ready for ERP, Accounting & E-Commerce:** Ideal for cross-border e-commerce sellers, accounting automation, financial dashboards, and remittance comparison tools operating with Vietnam (VND).
- **Structured Dataset Output:** Outputs exact `oneUnitInVnd` rates and pre-calculated `convertedToVnd` amounts for any custom input value.
